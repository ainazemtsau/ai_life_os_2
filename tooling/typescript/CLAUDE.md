# tooling/typescript/

Shared TypeScript configurations for libraries and Next.js apps.

## Files

| File           | What                                      | When to read                              |
| -------------- | ----------------------------------------- | ----------------------------------------- |
| `package.json` | Package metadata                          | -                                         |
| `base.json`    | Strict base config (all packages extend)  | Modifying shared compiler options         |
| `library.json` | Config for library packages               | Adding library-specific TS options        |
| `nextjs.json`  | Config for Next.js apps                   | Adding Next.js-specific TS options        |
